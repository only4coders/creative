# Venuefy

Phase 1 homepage for an Australian restaurant and hospitality marketing agency.

## Run locally

From this directory run `python3 -m http.server 8000`, then open `http://localhost:8000`.

## Phase 1 scope

- Responsive homepage with hero, approach, services, reporting concept, audience and closing CTA.
- Basic SEO metadata, semantic headings, mobile navigation and reduced-motion support.
- Dashboard graphic is explicitly illustrative; it does not claim actual client metrics.

## Planned Phase 2

- Verified work/case studies and FAQs, location discovery, fuller footer and production contact/booking integrations.
- Replace external hero stock image with a licensed, optimised local asset.
- Confirm legal business name, location, contact address, social links and domain before publishing.

The contact section is intentionally informational until a verified destination and booking link are supplied. No lead submission is implied.
